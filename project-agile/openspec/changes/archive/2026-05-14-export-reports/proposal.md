## Why

Evaluation results live inside the app. There is no way to share findings with a manager, compliance officer, or external auditor without giving them access to the platform. The "Export as Compliance PDF (Draft)" button already exists in the UI but does nothing.

## What Changes

- Every report detail page (RunReport, BiasVerdictReport, ComparisonReport) gets a working **Download Report** button
- Clicking it generates and downloads a **self-contained HTML file** — opens in any browser, looks professional, can be emailed or saved to SharePoint
- No new server-side dependencies (generated inline as a string, pushed to the browser via JS interop)

## Capabilities

### New Capabilities
- `report-export`: Generate and download a self-contained HTML compliance report for any report type (RunReport, BiasVerdictReport, ComparisonReport)

### Modified Capabilities
- `reports-detail`: Wire up the existing "Export as Compliance PDF (Draft)" button to call `report-export`
- `bias-verdict-detail`: Add Export button
- `compare-report-detail`: Add Export button with side-by-side model columns

## Impact
